# Project Echo logo assets

All assets in this package are derived from the exact logo image supplied by the Project Echo owner.
The artwork, colours, background, letterform and sound-wave motif have not been redesigned.

## Paths

- `assets/icons/app-icon.png` — 1024x1024 master application icon
- `assets/icons/app-icon.ico` — Windows multi-resolution icon
- `assets/icons/app-icon.icns` — macOS multi-resolution icon
- `assets/tray/tray-icon.png` — 32x32 tray icon
- `assets/tray/tray-icon@2x.png` — 64x64 tray icon for higher-density displays
- `assets/tray/tray-16.png` through `tray-128.png` — same artwork at common tray sizes
- `LOGO-SOURCE.png` — original source image

All tray variants retain the full square logo. No listening/processing colour variants are included.
